መግቢያ

ግዕዝ ስክሪፕት የአማርኛ ፕሮግራሚንግ ቋንቋ ነው። ይህ ቋንቋ በቀላሉ የኮድ መጻፍ ይፈቅዳል። የግዕዝ ስክሪፕት በተለዋዋጮች እና ተግባራት ላይ ይተካል።

ስክሪፕት ስርዓት

ግዕዝ ስክሪፕት የተመለከተ ስርዓት አለው። እንደ ዚህ ይመስላል:

ይሁን ስም = "ከበደ";

ይህ የተመለከተ ስርዓት ይሁን ይባላል።

ቁልፍ ቃላት

እነዚህ የግዕዝ ስክሪፕት ቁልፍ ቃላት ናቸው:

ምሳሌዎች

እነዚህ የግዕዝ ስክሪፕት ምሳሌዎች ናቸው:

መሰረታዊ ተለዋዋጮች


                ይሁን ስም = "ግዕዝ";
                ቋሚ PI = 3.14;
                አትም(ስም);

ቁጥጥር ፍሰቶች


                ይሁን ውጤት = 75;

                ከሆነ ውጤት >= 90 {
                    አትም("A+");
                } ከልሆነ ውጤት >= 80 {
                    አትም("A");
                } ከልሆነ ውጤት >= 70 {
                    አትም("B");
                } ካልሆነ {
                    አትም("C");
                }

ድግግሞሽ (Loops)


                // ለ loop
                ለ(ይሁን i = 0; i < 5; i++) {
                    አትም(i);
                }

                // እስከ loop
                ይሁን count = 0;
                እስከ(count < 5) {
                    አትም(count);
                    count++;
                }

ስብስብ ኦፕሬሽኖች


                ይሁን ቁጥሮች = [1, 2, 3, 4, 5];

                // ጨምር እና አውጣ
                ቁጥሮች.ጨምር(6);
                ቁጥሮች.አውጣ();

                // ቅዳ - እያንዳንዱን ቁጥር በ2 ያባዛል
                ይሁን እጥፍ = ቁጥሮች.ቅዳ(x => x * 2);

                // አጣራ - ከ3 በላይ የሆኑ ቁጥሮችን ያወጣል
                ይሁን ትላልቅ = ቁጥሮች.አጣራ(x => x > 3);

                // ቀንስ - ሁሉንም ቁጥሮች ይደምራል
                ይሁን ድምር = ቁጥሮች.ቀንስ((a, b) => a + b, 0);

መደብ እና ወራሽነት


                // መደብ መፍጠር
                መደብ ሰው ለመፍጠር {
                    ገንቢ() {
                        ይህ.ስም = "አብርሃም";
                        ይህ.ዕድመ = 25;
                    }

                    መግለጽ() {
                        አትም(`ስሜ ነው ${this.ስም} ዕድመዌም ${this.ዕድመ} ነው`);
                    }
                }

                // ወራሽ መደብ
                መደብ ተማሪ ወራሽ ሰው {
                    ገንቢ() {
                        በላይ();
                        ይህ.ክፍል = "ትምህርት";
                    }
                }

ቅደም ተግባር እና ጠብቅ


                // ቅደም ተግባር
                ቅደም ተግባር መርሐብ() {
                    ጠብቅ አዲስመርህ();
                    መልስ "ተሰራነው!";
                }

                // ቅደም ተግባርን መጠበቅ
                ቅደም ተግባር ጀምር() {
                    ጠብቅ መርሐብ();
                    አትም("ጀመርኩ!")
                }

ተግባራት

ግዕዝ ስክሪፕት ተግባራት ይወዳድራል። እንደ ዚህ ይመስላል:


                ተግባር ሰላምታ() {
                    አትም("ሰላም ዓለም");
                }

ተለዋዋጮች

ተለዋዋጮች ይሁን ይባላል:


                ይሁን ስም = "ግዕዝ";

ስሌቶች

የግዕዝ ስክሪፕት ስሌቶች ይሁን ይባላል:


                ሀ + ለ; // መደመር
                ሀ - ለ; // መቀነስ

ቁጥጥር ፍሰቶች

                ከሆነ ሁኔታ {
                    // እዚህ ይጻፉ
                }
